雪花是六重对称的：只要生成一条主臂，再旋转复制六次就行。

## 步骤

1. 把标题哈希成一个整数种子
2. 用种子驱动一个确定性随机数生成器
3. 沿主臂随机放置几个分叉点，分叉角度约 60°，左右镜像
4. 复杂度高时，在分叉上再长出小分叉
5. 旋转复制六份，中心补一个六边形

```ts
for (let k = 0; k < 6; k++) {
  const th = (k / 6) * Math.PI * 2;
  // 旋转主臂上的每一条线段
}
```

同一个种子永远长出同一朵雪花，所以封面不用存图片。
